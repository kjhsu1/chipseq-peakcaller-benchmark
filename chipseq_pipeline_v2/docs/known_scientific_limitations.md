# Known Scientific Limitations

- Controlled conclusions remain truth-aware but simulator-dependent.
- Peak versus plateau naming is only partially validated against real-data shape.
- MACS2 broad versus narrow mode is confounded with some current category labels.
- The current hilly family is better described as a dense hotspot/mappability process than a sparse hill process.
- BAM-only realism scoring is a comparative scorecard against real-data-derived reference ranges, not proof that any simulator category is biologically correct.
- The first-pass real reference set is incomplete until the broad worm study metadata and files are fetched and gated.
- Real-study-conditioned conclusions must be labeled as reference-based or truth-proxy based, never as exact truth.
